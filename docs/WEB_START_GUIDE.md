# 新手引导（A4）：开始之前、每一步的进度、没出图时先查什么

2026-11-12。对应 `docs/goals/alpha-value/TODO_ALPHA.md` 的 A4。命令行（`guide`、`tutorial`）和网页说同样的话，词在 `discprobe/web/home/guidance.mjs` 与 `discprobe/guide.py` 里各一份，顺序和意思一致。

## 有什么

- **开始之前的四件事**（网页大厅的“看新手引导”，设置菜单里也有；命令行 `tutorial` 开头同样四条）：图案怎么出来（盘面衍射）、要什么盘和光驱、要几张盘、照片拍坏了怎么办。熟悉 DIS 的人在同一页有“导入 DIS 预设”，打开大厅传真机那张导入导出的桌面，并说明导入的几何是 DIS 转换来的、不是 DP 自己测的。
- **盘数只有一种说法**：目标是第 3 张盘出成品，误差大时第 4 张，是目标不是保证。第 1 张测量盘，第 2 张检查盘（拍照看偏多少），第 3 张成品；误差大时第 3 张再检查一次，第 4 张成品。`guidance.mjs` 的 `discGoal`、`discRoute` 是唯一来源，标定页预算、新作品表单、教程都引它。
- **“你现在在哪一步”**：读 `/api/state` 的结果文件，不靠页面记忆。程序看不到的事写“还不知道”：测量文件做了不等于盘刻好了；检查盘有没有拍、偏多少；刻完有没有出图。这几行永远不会被打勾。刷新、关掉、过几天再来，都从磁盘重读。连不上本机服务时全部写“还不知道”。
- **标定页每个阶段**多两行：“还不知道”和“下一步”（`stepAdvice`）。没有进度可量的等待（生成镜像、读盘）直接说没有进度。
- **没出图**：先查光照，再看刻录报告（写入、关盘、回读），最后查几何。只有写入或关盘失败、或光照和报告都没问题而线条仍扭曲时才建议再刻一张，并写出原因。程序不会自动让人再刻。
- **教学动画**：四幕 SVG，没有 WebGL，没有 canvas。能跳过、能重看、能一幕一幕看；关掉动效、页面在后台、点了跳过时，停在最后一幕，四句话同时列在下面。键盘：Tab 到按钮，Enter；Esc 关闭，焦点回到打开它的按钮。

## 清掉的旧内容

- 新作品表单、标定页预算、CD 预览提示里互相矛盾的盘数（“至少 2 张，可能 3 张”“至少 3 张，精细标定在 DIS 里做”）。
- 预览页 CD 警告里“网页拍照标定还没做好，请先按 README 的 CD 路线”（网页已有拍照步骤，读不出来时才建议导出 DIS 预设）。
- 标定页检测光盘时一条按固定 5 秒填满的进度条，像在测量：现在条保持空着、写“读取中”，答案回来才满，也不再人为多等。

## 走查（一个人，不是统计）

用法：同一台电脑（有一个光驱，里面是一张写过的 DVD-ROM），空的结果目录，浏览器清掉本站的存储，只看页面，不看文档，从大厅走到“可以刻第一张成品”。没有刻盘，没有跑任何会动光驱的任务。标定页的阶段用单元测试加一次真页面（检测光盘阶段）核对，没有真的测量。

卡住的地方和处理：

| 卡点 | 处理 |
| --- | --- |
| 大厅没有任何地方讲流程，只有“新作品” | 大厅问候下加一行“第一次用？花两分钟看一下流程”，设置菜单加一行 |
| 新作品页写“先标定（约一小时，至少两张，可能三张）”，标定页写另一个数字，CD 页又是三张加 DIS | 一个说法，三处都引同一句 |
| 标定页没有告诉人哪些事程序还不知道 | 每阶段加“还不知道”“下一步” |
| 检测光盘的进度条按时间走，像在测量 | 改成空条加“读取中” |
| 引导第一版：脚注按钮写“读开始之前的四件事”，而人正在读 | 不把这一行放进进度里 |
| 第一版：“还没到 · 现在做这一步”自相矛盾 | 现在做的那一步只写“现在做这一步” |
| 第一版：核心的英文“not run yet”直接露出来 | 只在已完成时显示读数 |
| 第一版：“再刻的原因：……原因：……”重复 | 标签改成“什么时候再刻” |
| Esc 关闭后焦点丢了 | 回到打开它的按钮（设置里打开的回到设置按钮） |
| 引导的入口要等大厅图片取完才出现 | 引导先于大厅图片初始化 |

没修、不在这次范围：

- 手机拍照页和 `photocal.js` 里仍有“手机上传尚未接入”“照片读取尚未接入”“盘缘识别尚未接入”，是另一个会话的文件。后端接口已在，合并时要核对这几句是否还应出现。
- 390 px 宽下大厅页头放不下，设置按钮在屏幕外（页面宽 437 px），新手在手机浏览器里打不开设置菜单。引导入口在大厅问候下，不受影响。
- 标定页顶部的步骤尺在 800 px 宽时压到页头的工具按钮。
- 没有在真手机、真光驱、真盘上走。
