# 预先登记：随机数据盘的计时复测

在测量**之前**写下并提交，避免事后再按结果去解读。评估脚本是 `evidence/eval_remeasure.py`，也在测量前提交。

## 要回答的问题

1. 网格扫描测到的 U 形修正，是否只是旧计时拟合里 u、v 的统计误差？
2. 计时法自己报告的 1σ 是否诚实？
3. 不用扫描仪，单靠计时能否做到约 0.1°？

## 设置

| 项目 | 取值 |
|---|---|
| 光驱、盘 | 和旧测量完全相同：GH70N（H:）、同一张随机数据盘（DISCPROBE_RANDOM，RITEKF1） |
| 代码 | 提交 `f6d8276` 及以后，但 `geo` 的逻辑不再改动。包含整圈兜底（χ²/dof > 25 或残差 > 90° 时中止），以及按协方差选点、每第三级补最大空档 |
| 命令 | `python -m discprobe geo --drive H: --ref-lba 262336 --max-targets 36 --reps 32` |
| 参考 LBA | 262336，约 30 mm。旧测量是 1009840，约 42.6 mm，两者相距 12.6 mm，寻道路径和相对参考点的位置都会变 |

## 统计量与判据

- **"真值"：**旧计时拟合（`evidence/geo/random_disc_summary.json`）加扫描修正（`evidence/angle_correction.json`）。它自身的误差取扫描噪声，约 0.04°。
- **D：**在 25.8–54.4 mm 内，新的纯计时角度映射与"真值"之差，扣除常数整体转角后的峰峰值。
- **σ_c：**√(σ_new² + 0.04²)，其中 σ_new 是新一次测量自报的 `angle_sigma_measured_span_deg`。

| 结果 | 判定 | 含义 |
|---|---|---|
| D ≤ 2σ_c | 强通过 | U 形是统计误差，误差估计诚实 |
| 2σ_c < D ≤ 3σ_c | 通过 | 同上，但证据较弱 |
| D > 3σ_c | 不通过 | 还存在一种类似 u、v 偏移的系统误差（例如固定的位置延迟）；不得写"不用扫描仪也能到约 0.1°" |
| 测量范围没有覆盖 25.8–54.4 mm | 不完整 | 只报告，不下结论 |

**写"不用扫描仪约 0.1°"的附加条件：**判定为通过或强通过，并且 D ≤ 0.15°。

## 参照：旧测量本身的位置

用同一脚本评估旧测量：D = 0.309°，σ_c = 0.130°，D/σ_c = **2.37**。按 3σ 算通过，按 2σ 算不通过，而且 D 远大于 0.15°。所以这次复测想要满足附加条件，需要明显更小的 D。
