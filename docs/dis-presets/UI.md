# Preset interchange sheet

Mode: Operate. This extends the library; DESIGN.md and index.html remain the visual authority.

## Direction contract

THESIS: One sheet moves existing disc settings between applications. Each selectable row shows the original values and the limits of the mapping before import.

OWN-WORLD: Inherit Archivo, warm paper, ink, copper actions, four-pixel controls and the existing glass shadow. No imagery or additional palette.

STORY: Pick or drop a DIS file, inspect each preset, select rows and import. Choose a saved DP preset to download its DIS object or install with the existing backup rules. Errors remain visible beside the operation.

FIRST VIEWPORT: A heading and close control sit above an import file control and list. The import action follows the list. A separate export section contains the saved preset selector and two named actions. A single scrolling sheet works at desktop and phone widths.

FORM: Extension of an existing surface, code-led. No new visual-world seed or generated assets.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
