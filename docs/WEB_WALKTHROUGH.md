# 网页走查：第一次用的人能不能从头走到尾

2026-11-11，分支 `web/walkthrough-20261111`（基于 `web/integrate-20261111`，并合进了 `core/burn-safety-20261111`）。

目标：每条主路径要么走完，要么停在一句说实话、告诉人下一步怎么做的话上。没有点不了的死路，没有假装做完的占位。

## 怎么走的

- 真实的网页后端（`webui.Backend`），配一台假光驱 `Z:` 和一个按剧本回放事件的假核心。假核心写的事件和真核心一样（`step`、`progress`、`burn_speed`、`verify_progress`、`burn_result`、`calibrated`、`error`、`tray`），测量结果复制自真实的结果目录（GH70N + RITEKF1 的 DVD、ATIP 97:26:66 的 CD），所以页面读到的是真数字。整个过程不碰任何真光驱，也没用 8772 端口。
- 剧本可以在走查中途改（比如“用户换上了新空白盘”），每次任务开始时重读。
- 在应用内浏览器里点页面（面板隐藏时用脚本触发点击），读页面文字和 DOM 判断停在哪里；刻录完成页和标定结果页另外截了图。

## 主路径

| 路径 | 走法 | 结束在哪 |
| --- | --- | --- |
| 新光驱 + 新 DVD（第一次） | 大厅“新作品” → 表单认出光驱里的 DVD-R（RITEKF1）不在盘库 → “先去标定” → 检测（只读）→ 生成测量镜像 → 按住刻测量盘 → 检查 → 测转速 → 测几何 → 保存预设 → “回到刚才那一步” → 表单自动选中刚标定的批次 → 放图 → 预览生成刻录文件 → 刻录页发现光驱里是测量盘，引导换空白盘 → 按住刻录 → 写入、抽样回读 | **走完**：结果页分四项写“写入 / 关盘 / 回读 / 图案”，图案永远标“还没看”；“完成，回到桌面”回大厅 |
| 已标定的盘 | 新作品 → 选批次 → 放图 → 预览 → 刻录（换盘）→ 完成 | **走完**，同上 |
| 先画、没标定 | 新作品（批次“先不填”）→ 放图 → 预览“生成刻录文件” → “这种盘还没有测好的盘面几何” | 按钮变成 **“先标定这批盘”** → 标定 → 回到预览，生成、刻录照常 |
| 从盘库标定新盘 | 盘库 → 新盘位置 → 标定（同第一条） | **走完**：预设已保存 → 回到首页 |
| 刷新或关掉页面 | 标定刻测量盘时刷新 | 页面重开后自动接回正在跑的核心任务，跑到结果，能保存 |
| CD（Windows） | 新作品认出 CD-R → 先去标定 → 生成测量镜像 → 页面说“这台电脑上还不能从这里刻 CD，右键 .iso 选‘刻录光盘映像’” → 用户刻好后“检测刻好的盘” → 勾选“这是测量盘” → 测转速、几何 → “查看 CD 标定下一步” | **诚实的结尾**：“网页的 CD 拍照标定还没做好……导出 DIS 预设后在 DiscImageStudio 做精细标定”（README 的 CD 路线），预设已保存；画图、预览有 CD 警告；刻录页同样指向 Windows 自带刻录，主按钮“完成，回到桌面” |

## 恢复路径

| 情况 | 页面怎么说 | 下一步 |
| --- | --- | --- |
| 几何“噪声太大” | 读数太乱，不能依赖；保留测量盘 | “检查转速并重测” → 重测通过后可保存 |
| 几何“中途停了” | 不能当整张盘的结果；详情里有避开的方法 | “检查转速并重测” |
| 刻测量盘中途失败 | “这一步没有完成”；测量盘写了一部分，不能再用，换一张同批空白盘 | “重新检测” → 换盘后直接刻（不重复生成镜像）→ 走完 |
| 刻测量盘后盘不见了 | 光驱里没有准备好的盘，放回测量盘再检测 | “重新检测” |
| 盘的类型不对 | 光驱里是 X 盘，这里标定的是 Y | “重新检测” |
| 没有光驱 | 标定：没找到光驱，接好再检测（中途插上的光驱会被认出）；刻录：没找到光驱；底栏“未发现光驱” | 刻录页另有“用别的软件刻录”和文件路径 |
| 刻录中途失败 | “这次没有刻好” + 核心给的原因；失败建议（换盘、换个速度，慢不一定更好） | “准备另一张空白盘” → 换盘 → 可再刻 |
| 刻录没开始（比如盘不是空白） | “还没有开始刻，盘没有动过”，这张盘还能用 | “重新检查光驱里的盘” |
| 回读抽样有坏块 | 标题“写入完成，请检查回读结果”，回读一项标黄，列出 LBA 和大概半径 | 先看图，再决定换速度重刻；“返回预览”可再刻 |
| 等换盘超时 | 等了一阵没看到换盘 | “重新检查光驱里的盘” |
| 生成刻录文件失败 | “没有生成出来。”加核心的原因 | “重新生成” |

## 这次改掉的死路和假话

- 新作品表单：光驱里是没登记的新盘时，唯一的按钮“新开一包 · 登记”只弹“这一项以后接上”。现在给“先去标定”，“新开一包”在接进核心之前先藏起来。
- 预览：没几何时只有“重新生成”。现在是“先标定这批盘”，标完回到预览。
- 标定从表单或预览打开时，保存后整页刷新、丢掉画好的图。现在回到打开它的那一页，并选中刚保存的批次。
- 中文计划名（默认建议就是中文）生成的 ISO 文件名以“-”开头，核心拒收，报英文“path must stay inside the workspace”。现在保留任何文字的字母，不以“-”开头。
- 标签页在后台时，生成刻录文件卡在“正在画整张盘的设计图”（等一帧永远等不到）。现在 100 ms 后不等了。
- 刻录没开始也说“这张盘可能写了一部分，不要再用”，会让人白扔好盘。现在按有没有写入进度、有没有刻录结果来分。
- 失败只显示“Job failed (1)”。现在显示核心最后的错误或最后一行；任务结束太快、页面错过事件时，从任务保存的事件里取。
- 标定停下时显示英文原因、标题还写“正在刻测量盘”。现在是人话加下一步，标题改成“这一步没有完成”。
- Windows 上的 CD：核心没有 CD 刻录（`burner.WindowsDVD`），页面却让人按住刻录，失败后兜圈子换盘。现在照 `guide.burn_steps` 指向 Windows 自带的“刻录光盘映像”。
- 刻完只有一句“光盘刻好了”。现在“写入 / 关盘 / 回读 / 图案”分开写；关盘是刻完重新读盘得来的（`disc_report` 新增 `closed`，来自 READ DISC INFORMATION）；图案只能人看，永远不标绿。成功时不再显示“刻录失败”那段建议。
- 盘库：标定保存的预设用绝对路径记进 `catalogue.json`，同一批盘在下拉框里多出一条用预设内部名字命名的“批次”。现在存相对路径，旧的绝对路径也认得。
- 一个被手动删掉的任务目录会让所有页面的事件流断掉。现在跳过。
- 刻录后建议从“降低刻录速度”改成“换一个速度，慢不一定更好”（核心和网页同步，依据 burn-safety 的 4x/8x 对比）。

## 声音

用户选的音效（`docs/goals/sfx/CHOICE.md`）：步骤依次 0–3（标定：刻、检查、测转速、测几何），全部完成 4（标定测量可用、刻录写完且回读干净），可以补救的问题轮流用 Error / Error-B，真正失败（刻录写了一部分后停了）用 Error-long。两个 success 文件不用。默认开、音量 0.3，用户操作过页面才响。页头有开关（M 键，也在快捷键表里）；手机宽度下页头放不下，设置菜单里也有“声音 开/关”。每个声音旁边都有文字，声音只是第二条通道。

## 还没做或没验证的

- **全部只在假光驱上走过。** 换盘等待、刻完重新读盘看关盘、抽样回读，都要在真 GH70N 上再看一遍（真盘的关盘状态、刻完马上读的就绪时间）。
- **手机拍照上传和自动标定**：核心里还没有（应是本机服务 + 终端二维码或 PNG）。页面没有假装有：CD 走 DIS 的路线，DVD 不需要拍照。`?mock` 演示模式里还留着一个写着“QR”的方框，只在演示模式出现。
- **“新开一包 · 登记”**（给已标定的批次登记新一包的张数）没接进核心，暂时藏起来。每桶剩几张目前只能在标定保存时填。
- **CD 在 Windows 上从页面刻**：核心没有，页面只给 Windows 自带刻录的指引；刻完后的四项检查这条路没有。
- 预设、ISO 显示的是相对工作目录的路径；要导入 DIS 时，用户得知道工作目录在哪。可以加“在文件夹里显示”。
- 中文 ISO 文件名在真 IMAPI 刻录上没试过（理论上 Windows 和 growisofs 都支持）。
- DIS 社区调研里的“加”项（一键问题报告、刻录时阻止睡眠、盘库里的批次/MID）没做，主路径通了以后可以排。

## 自己再走一遍

`devserve.py`（假光驱 + 剧本核心）和 `seed-walk.sh` 留在 worktree 里，没有提交：它们读主仓库 `results/` 里的真实结果目录，那些不在仓库里。`walk-scenario.json` 是剧本，例子：

```json
{"disc": "written_dvd", "swap_to": "blank_dvd", "after_burn": "written_dvd", "burn": "readfail", "speed": 3}
```

`calibrate` 可选 `good / too_noisy / stopped_early / no_disc / burn_fail`，`burn` 可选 `ok / readfail / fail / notstarted`，`swap` 可选 `ok / timeout`。
