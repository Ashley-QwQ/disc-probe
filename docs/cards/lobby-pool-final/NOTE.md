## 桌面暖色与牛皮纸

暖色定义为 OKLCH H∈[30°,90°] 且 C>.02。只统计 desk_top ID=1 的完整覆盖像素，收进边缘并剔除前景 alpha；牛皮纸、灯罩、LED、地面和其它物件均不在桌面掩码中。暖色 **0 / 553037 = 0.000000000%**。

文件盒牛皮纸单独使用 kraft 系列 ID，保留完整覆盖、alpha=255、收进 3px、排除 7×7 通道极差>6 的线条邻域，色相比较只排除 C≤.005 的不稳定近灰像素（不套用桌面 C>.02 的暖色门槛）。共 36291 个同坐标像素。新旧圆均值色相 67.163114767° → 67.163114767°，差 **0.000000000°**，在 3° 范围内。逐像素绝对差中位 / p95 / 最大 = 0.000000000° / 0.000000000° / 0.000000000°；超过 3° 的比例 0.000000000%。不把区域均值的结论扩大为每个有损编码像素均满足 3°。像素选择与掩码见 surface-check.json、kraft-comparison-mask.png。
