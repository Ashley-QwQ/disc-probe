## 补充第 2 项（11-20，用户截图："左边是不是被裁掉了一块"）

左栏 `.col-l` 有纸色底（`design.css` 第 229 行），但 `.col section` 只有上下内边距（`padding: 14px 0 18px`），左右是 0。右边又因为 `scrollbar-gutter: stable` 留出了滚动条的位置，结果"Layers"、缩略图、Burn grid 按钮全都贴着左边缘，右边却空一截，看起来像左边被切掉了一块。右栏 `.col-r` 有 `padding:16px 12px`、圆角和投影，左右两栏不一致。另外，左栏内容在中途（"Files on the disc"）就截断了，下面其实还能滚，但没有任何提示。

- 左栏和右栏用同一套面板样式：内边距、圆角、投影都一样，不要另造新样式；
- 左栏可以滚动时，底部加一道渐隐或者别的提示，让人知道下面还有内容；
- 窄屏（≤1240 px 以及手机布局）下也要检查一遍。
