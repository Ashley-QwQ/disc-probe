## 阅读范围与判断尺度

本报告只读本地资料，不联网，不构建、不安装、不启动 DIS 或 DP。`DIS/` 表示 `D:/dis-study/DiscImageStudio/`；`DP/` 表示只读的 `D:/disc-probe/.claude/worktrees/webui-backend/`。证据中的行号均对应本次本地文件；区间表示需要一起阅读的几行。提交日志确认克隆 HEAD 为 **9b74ca3，2026-11-10**。这不是对下载 EXE 的运行验证。

**v1.5.0 和 main 必须分开。** 发布说明把 v1.5.0 对应到 `29b8cc1177c67a16b1ee5d2eb1a8c122f01cad17`；当前 README、源码和教程属于较后的 main。下文源码结论首先针对 main；只有发布说明或带版本的变更记录支持时，才明确归到 v1.5.0。不能把 main 新加的拖入图片、更新功能和设备信息页算成 v1.5.0 已发布功能。〔`release-notes.md:1–2,54–56`；`DIS/CHANGELOG.md:3–26`〕

“已解决”要求这项问题本身消失；“部分解决”表示有实质帮助但仍有人工成本或缺口；“未解决”限于检查范围内没有找到对应入口；“不清楚”用于证据不足。没有真实用户样本，不能从源码算出成功率、平均耗盘或平均耗时。

## 六项痛点：具体改变了什么

1. **应用内不是毫无引导，但还不是完整新手教学。** 启动代码载入设置、创建主窗口，首页给工程和模板入口；没有找到首次使用状态或全程教学分支。标定页则明确采用逐步展开的卡片，并有“当前记录属于另一个阶段”的处理提示。把“没有任何应用内指导”作为今天的评价不准确；把外部实操文档当作应用内教程也不准确。〔`DIS/src/DiscImageStudio.App/AppHost.cs:16–18`；`DIS/src/DiscImageStudio.App/Views/HomeView.xaml:13–59`；`DIS/src/DiscImageStudio.App/Views/CalibrationView.xaml:286–300`；`DIS/src/DiscImageStudio.App/Localization/Catalogs/CalibrationStages.json:38–41`〕

2. **排版能力已有明显基础，固定栅格仍在。** 多图可作图层，能改 X/Y 毫米位置、角度、缩放、显隐、顺序；main 还支持从资源管理器拖入多图。检查的设计视图和模型中，未找到专门的文字排版、矢量绘制、自动对齐或页面模板编辑工具；这是“未找到”，不是证明任何隐藏入口都不存在。〔`DIS/src/DiscImageStudio.App/Views/DesignView.xaml:14–50,125–150,180–185`；`DIS/CHANGELOG.md:18,23`〕

   正式图层合成用 8192×8192，设计预览用 2048×2048；输入图层解码上限还有 4096 像素。每毫米像素数由画布半径决定。按直径 116–120 mm **计算**，每格约 **14.2–14.6 µm**，所以用户记忆大致对，但这不是光盘本身“只能刻这个大小”，也不是照片导入上限。没有找到用户可改正式合成尺寸的设置。〔`DIS/src/DiscImageStudio.Imaging/RingImageQuality.cs:3–7`；`DIS/src/DiscImageStudio.App/ViewModels/DesignViewModel.cs:26–28,863`；`DIS/src/DiscImageStudio.App/Services/DesignComposer.cs:26–28,44–45`〕

3. **危险操作已有真实防线；预设正确与否仍要人判断。** 流式刻录要求先勾选确认，再弹出写入设备、内容和速度的确认窗，说明取消或断电可能废盘；来源或选项改变会使确认失效。底层按介质类型检查，拒绝非空白盘。v1.5.0 还按实际可写容量限制输出，严格遵守 CD 边界。它不是一个完全无检查的写盘按钮。〔`DIS/src/DiscImageStudio.App/ViewModels/BurnViewModel.cs:534–548,686–700`；`DIS/src/DiscImageStudio.Burning/WindowsImapiBurner.cs:887–889,1167–1247`；`release-notes.md:18`〕

   但容量相同不等于半径相同；教程仍要求自己选与实物对应的预设。当前检查能防止不少“写错类型、写不下、写到旧盘”，不能证明“这桶盘一定适合这个预设”。拟合偏差大、多解或搜索贴边也允许用户核对后应用。错误日志更完整，仍不等于系统能解释每种失败的物理原因。〔`DIS/docs/CALIBRATION.md:39,84–85,100`；`release-notes.md:19–20`〕

4. **手调变成了手量加自动求解。** 粗标点六个边界，程序读角度标记；边界标定描可见交界，程序反推半径；精标沿细臂描点，可自动拟合三次轨距分布。人不用自己把参数曲线一点点调到看起来直，但盘缘／孔缘控制点、测量点、候选吻合确认仍靠人。v1.4.0 发布说明已列出三阶段和三次轨距；v1.5.0 主要又改善拟合保存与恢复。〔`DIS/docs/CALIBRATION.md:15–17,58–63,81–101`；`release-notes.md:187–188,17`〕

5. **没有找到手机直接进入电脑标定流程的链路。** 当前导入入口是本地照片／扫描图文件选择框；在应用源码中未找到手机上传、扫码、相机采集入口。照片可无损嵌入标定记录，能省去以后找原图的麻烦；照片反光时也能重拍同一张盘，不必一张坏照片就再烧一张。但首次传图和重拍传图仍是用户自己的工作。〔`DIS/src/DiscImageStudio.App/ViewModels/CalibrationPhotoViewModel.cs:182–202`；`DIS/docs/CALIBRATION.md:13,61,121`〕

6. **Linux 已不再等于“没有版本”，但流程没有补齐。** v1.3.6 已引入实验性 Linux/macOS 离线 CLI，能从图片生成 CD 音轨、CD 数据镜像、DVD/BD ISO；v1.5.0 继续提供 x64/ARM64 包。Windows 桌面版包含设计、照片标定和即时刻录；Linux 的写盘交外部软件，不能把“有 CLI”宣传成“桌面操作完全相同”。〔`release-notes.md:244–245,30–47`；`DIS/README.md:97–101,121,139–144`〕

## 我第一次用 DIS：下载以后怎么办

以下扮演“我只想把喜欢的角色刻到家里的盘上”的用户。把官方确实教过的内容也算进来，不假定我一开始就会看扇区、轨距或拟合误差。

### 我能理解原理和开销吗

**我最先看到的是效果图和“图片变成盘面图案”，还不知道为什么。** README 的概述和快速开始告诉我能做什么，没用一屏解释“不同数据让刻出的微小纹理不同，在合适光照下形成明暗；软件还要把图片位置对到螺旋轨道上”。后一句是本报告的通俗概括；仓库更深入的解释在技术文档，谈跳变密度、黑白字节和几何映射，新手不容易从首页自然学会。〔`DIS/README.md:26–36,48–64`；`DIS/docs/DVD_ENGINE.md:100–106,132–142`〕

**我知道要空盘和刻录机，但没有开场总预算。** Windows 完整桌面流程需要 Windows 10 2004+ x64 或 Windows 11；main 另有 Windows 11 ARM64。Release 自带运行时，不需要我安装 .NET SDK。照片或扫描图二选一，因此扫描仪不是必需品，手机照片可以用；Linux/macOS 可以生成镜像，但要另找刻录软件，也没有这里同样的桌面标定流程。没有证据说明 DIS 必须使用 CAV 读盘的光驱。〔`DIS/README.md:50,97–101,121`；`DIS/docs/CALIBRATION.md:13,19`〕

**“通常要几张才认得出角色”没有可靠数字。** 用户提供的旧经验是 4–6 张；本次没有把它当成 v1.5.0 的统计。文档主线是粗标、边界、精标，然后再刻验证盘，按每轮一张新盘数，约四张用于走完这个示例；再刻角色图通常还要一张。另有三轮粗标的案例，会再增加两张，但文档明确说三轮不是要求。可靠预设也可能减少或跳过阶段。教程没有承诺第几张能辨认角色。〔`DIS/docs/CALIBRATION_TUTORIAL.md:3–5,29–33,72–81`；`DIS/docs/CALIBRATION.md:5,107`〕

**我开始用的是标准值或别人的实测预设，不是程序已经精确量过我手里的盘。** 标准 DVD 预设用 24–58 mm，标准 80 分钟 CD 用 24.5–56.8 mm；库里也有带实测半径和轨距系数的品牌预设，所以不能说每个人都必须从标准值重新开始。问题是这些数值不是本机对本张空盘进行计时精测的结果；容量读回也不能直接确认全部几何。官方案例还特别说明示例起点不同于当前内置值。〔`DIS/src/DiscImageStudio.Core/Presets/built-in-disc-presets.json:6–13,56–78`；`DIS/docs/CALIBRATION.md:39`；`DIS/docs/CALIBRATION_TUTORIAL.md:39–44`〕

### DIS：我会卡住或需要判断的点，共 12 项

这是上述首次路线中的**风险点计数**，不是声称每个新手都会失败，也不重复计算每个鼠标点击。官方文档已经给答案、但必须离开主线去找的，也明确写出。

1. **原理门槛**：为什么写数据能显图，不在首页快速说明。〔`DIS/README.md:34–36,48–64`〕
2. **兼容性门槛**：家中光驱／盘是否真的适用，开头概括不能代替实测。〔`DIS/README.md:9,203–204`〕
3. **预算门槛**：开始前没给总张数和总时长。〔`DIS/README.md:48–64`；`DIS/docs/CALIBRATION_TUTORIAL.md:5`〕
4. **预设门槛**：按品牌选了，仍不知道这一桶是否匹配。〔`DIS/docs/CALIBRATION.md:39`〕
5. **流程顺序门槛**：快速开始直接设计和刻录，我不一定知道应该先标定。〔`DIS/README.md:52–64,79–89`〕
6. **无图分诊门槛**：成功写盘却无图时，没找到看盘光照／几何／写盘三路分诊。〔`DIS/README.md:60–64,203–204`；`DIS/src/DiscImageStudio.App/ViewModels/BurnViewModel.cs:745–750`〕
7. **照片质量与传输门槛**：重拍和电脑传图仍由我操作；说明能减轻但不能消除。〔`DIS/docs/CALIBRATION.md:13–17,61`；`DIS/src/DiscImageStudio.App/ViewModels/CalibrationPhotoViewModel.cs:184`〕
8. **照片量尺门槛**：要分清实体外缘、孔缘和记录区，找错圈会把后续测量带偏。文档已有答案。〔`DIS/docs/CALIBRATION.md:14–29`〕
9. **粗标出口门槛**：什么时候应该重拍、再粗标或进入边界标定，不是每批盘固定一次。〔`DIS/docs/CALIBRATION.md:61–69`〕
10. **描点门槛**：边界与细臂量法不同，反光处要补段，覆盖必须足够。文档有明确规则。〔`DIS/docs/CALIBRATION.md:81–100`〕
11. **拟合判断门槛**：候选、搜索范围和吻合警告仍要人工确认。〔`DIS/docs/CALIBRATION.md:84–85,99–101`〕
12. **参数交接门槛**：记录、应用、预设和工程是不同状态，照片还必须配原生成参数。〔`DIS/docs/CALIBRATION.md:109–119`〕

**耗盘与时间估算，不是实测平均值：** 若我没有可靠预设，先盲试一次角色图，再按三阶段、验证、最终角色图走，可能总共 **5–8 张、3–8 小时**；顺利使用匹配预设可能只用一张，复杂情况也可能超出上限。估算按每次烧盘约 10–25 分钟，加每轮拍摄、传图、矫正、取点约 15–40 分钟和阅读排错时间计算；DIS 没给这个统一时长。三阶段、验证和重复粗标的张数依据来自教程；单次烧盘时长只是结合 DP 产品文档作的工作预算，不能视为 DIS 性能测量。〔`DIS/docs/CALIBRATION_TUTORIAL.md:5,29–33,72–81`；`DIS/docs/CALIBRATION.md:107`；`DP/PRODUCT.md:46`〕

其中 **3–6 张标定／验证盘是方法成本，不能全部叫“白费”**；真正额外浪费，保守可预算 **0–3 张、约 0.5–3 小时**，来自过早试角色图、错配记录、无图就重烧或错误取点后复刻。这也是估算；用户原先 4–6 张的经验只能作为个人经历，不能证明最新版必定同样。〔流程依据：`DIS/docs/CALIBRATION.md:39–42,63,85,107–119`〕
