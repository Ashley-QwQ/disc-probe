# Disc Neo {{VERSION}}（预览版）：DVD 纹理图谱

[English](README.md) · [字段说明](SCHEMA.md) · [来源记录](PROVENANCE.json) · 许可：GPL-3.0-or-later

把一小段字节当普通数据，在 DVD±R 上反复刻下去，轨道上的记录点就排成了一道光栅。光线合适时，数据面会显出颜色，
颜色由这段字节的重复周期决定。这个数据包就是这类字节段（下文叫"纹理"）的查询表：每个周期区间里目前找到的最好
纹理是哪段、它的能量有多集中在想要的周期上、这一带搜到了什么程度。

**先看这个：** 用浏览器打开 `index.html`（双击就行，不用联网）。它把所有搜索目标画在一张周期图上，点任意一格就能看冠军和
全部次名，也能按编号或 spec 查。下面的文件是同一份数据，给脚本和 agent 用。

里面有：

- **{{SINGLES}} 个单周期纹理**，每个都有固定编号，并且在完整的 DVD ECC 块上实测过（`atlas/dvd/singles.csv`）。
  每条都给出周期、纯度、低频风险，以及在什么视角因子范围内显蓝、显绿、显红。
- **{{TWO_LINE}} 个双周期、{{THREE_LINE}} 个三周期组合**（`atlas/dvd/multi_line.csv`），用来做单个周期做不出的
  颜色，比如白、灰、品红。
- **不只冠军，前几名也收录**（`atlas/dvd/candidates.csv`、`candidates.json`）：{{CAND_TARGETS}} 个目标共
  {{CAND_ROWS}} 个按名次排好的候选，其中 {{CAND_WHOLE}} 个整块实测过，{{CAND_PROXY}} 个只有 GPU 近似值。为什么要收录，
  见[为什么收录次名](#为什么收录次名)。
- **全部 {{COVERAGE_ROWS}} 个搜索目标的覆盖表**（`atlas/dvd/coverage.csv`）：搜没搜过、搜得多密、收敛没有、
  目前最好的纯度。
- **完整导出**（`atlas/dvd/atlas_dvd.json`），另外还有亮度阶梯（{{LADDER}}）、暗色纹理（{{DARK}}）、二阶和三阶
  衍射目标（{{ORDER2}} / {{ORDER3}}）、所有整块实测过的候选（{{OBSERVATIONS}} 条），以及早先色板的全部
  {{IMPORTED}} 条观测。
- **A3 v3 纹理色卡**（`texture-cards/`）：637 个纹理在整个视角范围里的预测颜色，白光 LED 和 D65 日光各一份，
  附数据和生成脚本。

## 为什么收录次名

图谱的每个格子（一个搜索目标：一个周期区间、一种混色或一档亮度）都按名次列出搜索找到的所有不同字节段，不只留
第一名。颜色一样、写法不同的字节段本身就有用：

- **在彩色区里藏数据。** 如果有 16 个字节段颜色一样，每个就能代表 4 位数据，彩色区看起来还是一整片，里面已经
  存了东西。
- **冠军刻不好时换备胎。** 最好的那个在你的光驱上难刻或难读，下一名可以直接顶上。
- **当灰阶用。** 颜色相同、纯度低一些的，色相不变、亮度更低，可以做深浅。
- **打散纹路。** 几个等价的字节段沿轨道轮流用，能让规则的纹路不那么显眼。
- **混色。** 有些次名带第二根谱线，可以拿来做混色的起点。

**这一版每格存的是：** 合并后 GPU 搜索的前 4 名、五次独立重跑各自的前 4 名，加上目前能找到的全部整块测量结果
（主要是每次重跑的决赛候选用 CPU 在完整块上重测的结果，也有早先轮次和旧色板导入的），按字节段去重。整块实测的排在前面，排序规则和选冠军的规则一样，所以
第 1 名一定是公布的冠军；只有 GPU 近似值的排在后面，它们的纯度是估计值，`basis` 一列写明了。

**下一版：** 本轮结束后会补一轮覆盖全部周期的均匀加密，那时改成按容差收录：同一个周期格里、纯度不低于冠军的
80%、风险不比冠军差的都收，每格最少 8 名、最多 16 名。

## 颜色要靠模型算，别靠看表挑

你看到的颜色取决于光源、相机或眼睛的位置；拍照时还取决于手机型号、闪光灯在镜头旁边的位置。同一个纹理，这张
照片里是蓝的，换个机位可能就是绿的。所以这个包故意不提供"随手挑颜色"的列表，而是给原材料：

- 这里的实测数据（周期、纯度、视角因子窗口）；
- [disc-probe](https://github.com/Ashley-QwQ/disc-probe) 里的 ISO 求解器，把设计变成能刻的光盘镜像；
- 颜色计算模型（`texture-cards/scripts/`，以及 disc-probe 里的模拟器）。

建议的用法是配合 AI 编程助手（agent）：告诉它你的手机、光源和拍摄位置，让它从这份数据里挑纹理，并按你的条件
模拟出颜色。

## 怎么查

**按周期查。** 周期为 P（µm）的光栅会把波长 λ = 1000 · P · δ nm 的光送到你眼前；δ = sin θ入 + sin θ出（沿轨道
方向）是视角因子，由光源和相机的位置决定。`singles.csv` 给出每个纹理显蓝（440–490 nm）、显绿（510–590 nm）、
显红（610–690 nm）时对应的 δ 范围。

```python
import csv
rows = list(csv.DictReader(open('atlas/dvd/singles.csv', encoding='utf-8')))
# 周期在 0.95–1.05 µm 之间实测最好的纹理，读盘风险低的排前面
near = [r for r in rows if 0.95 <= float(r['period_um']) <= 1.05]
near.sort(key=lambda r: (not r['risk'].startswith('low'), -float(r['purity'])))
for r in near[:5]:
    print(r['id'], r['rev'], r['spec'], r['period_um'], r['purity'], r['risk'], r['delta_green_lo'], r['delta_green_hi'])
```

**按印出来的色块查。** 按这份图谱印的色块上写着 **编号 + rev + spec + 周期**，比如
`DVD-S-B0042-K96-A123abc rev 2 A37062 0.853 µm`。拿编号去任何一个 CSV，或 JSON 里的 `targets` /
`atlas_target_winners` 查。如果你色块上的 rev 比现在的小，说明后来找到了更好的纹理；旧的那个仍保留在历史里
（JSON 的 `observations`）。

**用眼睛看。** 打开 `texture-cards/texture_cards_v3_led.pdf`：每一行是一个纹理，沿着一行往右看，就像在慢慢倾斜
光盘。

## 数字是什么意思（简版）

- **纯度（purity）**：去掉直流后，这段数据的信号能量有多少正好落在想要的周期上。用真实的 EFMPlus 编码、
  加扰和 DSV 控制，在完整的 DVD ECC 块上测。1.0 就是一条完美的单线。纯度越高，颜色越干净、越饱和。
- **F512_percent / 风险（risk）**：数据有多常偏向一种极性的长段，这是已知的读盘出错原因。`risk` 是按模型阈值
  打的标签，不是在真光驱上的读盘测试。
- **状态（status）**：`todo` 还没搜，`searched` 已搜，`converged` 达到停止条件。其余见 SCHEMA.md。
