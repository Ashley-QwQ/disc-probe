SourceHanSansSC-Heavy-subset.woff2  Adobe Source Han Sans CN Heavy derivative  OFL-SourceHanSans.txt
Internal family: Disc Title SC Heavy (renamed because OFL reserves "Source").
Source: Adobe official source-han-sans release 2.005R, 19_SourceHanSansCN.zip,
SubsetOTF/CN/SourceHanSansCN-Heavy.otf (weight 900).
https://github.com/adobe-fonts/source-han-sans/releases/download/2.005R/19_SourceHanSansCN.zip
Rebuild from repository root: python tools/subset_title_font.py path/to/SourceHanSansCN-Heavy.otf
Requires fontTools[woff] and Brotli. No download during rebuild.
Character set: Han characters and common Chinese punctuation in every .html/.js/.mjs
under discprobe/web and disclab/web (excluded paths pruned), plus GB2312 level 1
(3755 characters generated by Python's gb2312 codec), plus explicit punctuation.
No Latin letters or digits. titles.css applies only to headings/title labels;
Archivo remains first for Latin/digits, body text keeps the existing system face.
The independent Lab static root carries an identical font/CSS/license copy.
