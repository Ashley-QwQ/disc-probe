# Disc Lab 独立包验证记录

日期：2026-11-13。环境：Windows、Python 3.13.14。

## 改了什么

- 中间 ISO 全部改放 `LAB/iso/`，用完或步骤失败后清理；A3 光谱表重建改为显式传 `--a3 SOURCE_FOLDER`。历史测试报告中的本机路径替换为相对占位符。
- 启动钩子按解包位置找旁放的 `discprobe/`，否则用当前解释器安装的 wheel；CLI 和子进程都检查版本，缺失或不等时只用一句话退出。
- 增加英文、中文说明，完整保留原实测／假设表，并解释照片、网页、上传、分数和已知局限。
- 增加 12 张 DVD-R 配置及 PowerShell、Bash 示例。三步为建盒、`loop geo`、`score`；拒绝覆盖已有实验目录。快速参数只影响示例的镜像大小和读取次数，不改变原默认值。
- 增加独立 ZIP 生成器和许可证副本。ZIP 只带 `disclab/`，不含 disc-probe、Python、实验结果和缓存。

## 包和验证边界

本地产物为 `dist/disc-lab-1.0.0.0-alpha.zip`，旁附 `dist/SHA256SUMS.txt`；已检查 ZIP 完整性、清单和解包文件内容。当前受保护的 `discprobe.version.__version__` 是 **0.1.2.1**，因此包按完整字符串要求 **0.1.2.1**。文件名是任务卡要求的发布名，不能说明已经适配 1.0.0.0-alpha。实际发布前必须让配套版本和 `compat.py` 一致，再重新验证；本任务未发布任何内容。

安装验证使用本地构建的 `disc_probe-0.1.2.1-py3-none-any.whl`，通过 `pip --no-index --no-deps` 安装到 `venv --system-site-packages`，复用主机已有数值／图像依赖。旁放布局验证使用源码 `discprobe/`，没有测试已发布 Windows 完整 ZIP 自带的 Python。原始本地日志、分数 JSON 和安装环境保留在被忽略的 `_package_checks/`，不进入分发 ZIP。

**未验证：Linux、完整照片循环、A3 表重建、真实网页会话和真实上传。** Git Bash 是 Windows 上的 Bash，不能算 Linux 验证；网页和上传测试使用模拟子进程和 HTTP。照片生成器仍只支持 A5、B9 和随机数据纹理，多字节 `checkdisc` 图案会空白；CD、BD 只支持几何。原有模型局限和真值／评分公式都保留。

所有实际写入均为实验光驱的虚拟写入，没有接触真实光驱或物理刻录，没有网络访问或启动服务器，CPU 重进程未超过四个。没有 commit、push、stash、reset 或切换分支；源码修改只在 `disclab/`。
