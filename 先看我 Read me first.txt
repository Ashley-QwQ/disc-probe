Extract the entire ZIP to a writable folder before starting disc-probe.
Windows x86_64: Double-click “开始 Start (Windows).bat”.
Linux x86_64: Run bash start-linux.sh in the extracted folder.
The full package includes Python and its dependencies. See INSTALL-linux.md
for Linux drive permissions and hardware test status.
