13 次真盘 `geo` 测量组成 78 个无向配对（交换来源盘和目标盘后共 156 个方向）。132/156 个方向满足照片读取器的两个几何形状门槛。主会话复核后以同盘复测误差作为比较基线，允许同一台光驱、同 MID 的已有标定进入 B 段。跨批次、跨机器仍缺少可核实的本地配对。

## 计算和判据

以目标盘 B 的物理半径 `r` 为自变量，在 25–57 mm 每 0.01 mm 反解 B 的通道位地址。用同一地址求 A 采样设计的半径和角度，再减出实际落点与设计落点的差。角度用 [`calib.theta`](../../discprobe/calib.py) 与 [`imagedisc._sample`](../../discprobe/imagedisc.py) 的顺时针约定，保留整圈。位置误差用两落点的平面距离。首次对比去掉常数整体转角，以免盘面摆角影响形状；JSON 也保留未减转角的原始误差。

在 `pcal.design_burn()` 默认六个读取区的径向采样均值（28.75、32.50、36.75、41.50、47.25、53.50 mm）取理想角差，在每个方位重复，用现有 `pcal.fit_votes` 拟合整体转角 `c` 和沿轨距离 `L`。在全半径减去 `c + L/r`，并统计两次实测区间交集上的剩余误差。保留源摘要记录的角度修正能力，实际入对的摘要均未声明修正文件。本计算只替换几何，真实写入偏移、读出延迟、摄影配准、纹理可见度及投票可信度未测。

| 代码中的判据 | 应用方式 |
| --- | --- |
| [`pcal.GATE`](../../discprobe/pcal.py) | 理想投票残差 RMS ≤ 0.8°、逐个去掉一个半径区重估 L 的极差 ≤ 0.8 mm。`verdict` 分别以 `large_residual` 和 `shape_not_1_over_r` 拒绝超限数据。这里仅验证形状两项，实际照片及多照片一致性未验证。 |
| [`evidence/eval_grid.py`](../eval_grid.py) | 刻图精度沿用网格盘 3 登记的三项标准。对修正后曲线取 25–55 mm 的 15 个必需分箱中位数，去整体转角后比较 RMS ≤ 0.06°、峰峰值 ≤ 0.20°、二次分量 ≤ 0.10°。这是仓库已有的网格实物验收判据，本次套用到几何计算曲线。 |
| [`checkdisc.run`](../../discprobe/checkdisc.py) 和 [`coverage.range_warning`](../../discprobe/coverage.py) | 检查盘拒绝覆盖不了 26.2–57.0 mm 的测量；`image` 会对可写的作品半径执行同一个范围检查。另按卡要求检查 25–57 mm 的覆盖，超出实测的计算点仍保留，但标为外推。 |

`image` 的抽样回读校验的是镜像字节。`disexport` 的 5° 拒绝线检验预设格式拟合到输入几何的误差，`coverage` 的 0.6° 线检验由协方差得到的条件不确定度。三者的测量量均与跨盘模型差不同，计算只使用上表与该差值对应的判据。

## 重跑

从 worktree 根目录运行。脚本需要 `rg` 和项目 Python 依赖，三处输入根目录可以通过 `--probe`、`--integ`、`--archive` 指定。脚本只读输入，生成包含来源 SHA-256、排除原因、全部方向配对和社区旁证的 JSON。

```powershell
$env:TEMP = 'D:/dp-dev/tmp/starter'
$env:TMP = $env:TEMP
$env:PYTHONDONTWRITEBYTECODE = '1'
python -X utf8 evidence/starter/compare.py --out D:/dp-dev/tmp/starter/pairs.json
python -X utf8 evidence/starter/compare.py --out D:/dp-dev/tmp/starter/pairs-repeat.json
Get-FileHash -Algorithm SHA256 -LiteralPath D:/dp-dev/tmp/starter/pairs.json,D:/dp-dev/tmp/starter/pairs-repeat.json
```

两次输出 SHA-256 均为 `8438293926f535e4d90364d38b052a828de67665aceba13183ac5a5fb6520033`。向同一模型注入 0.3 rad 整体转角和 1.25 mm 沿轨偏移，拟合得到 `1.2500000014 mm`，最大剩余角差 `1.7e-9°`。正反方向的两套形状判定一致，L 之和最大绝对值 `1.4e-6 mm`，来自目标半径坐标和数值计算的差别。
