# disc-probe

Disc-probe measures optical discs and makes disc images that show pictures when recorded. Use the command line as the primary interface and check the installed CLI help for options.

- For a colour picture on a DVD, follow [the disc-colour skill](skills/disc-colour/SKILL.md).
- Ask for explicit user confirmation before burning or erasing a disc.
- Before changing code, read [DESIGN.md](DESIGN.md), [STYLE.md](STYLE.md), the [manual](docs/MANUAL.en.md) and [API versioning](docs/API_VERSIONING.md).
